# gtg-grading-presets-kdenlive
This repository contains the color grading presets made by me.

## Feel free to drop it in 

Linux:
```bash
~/.local/share/kdenlive/effects
```

Windows:
```bash
C:\Users\<YourUsername>\AppData\Roaming\kdenlive\effects
```

or use environment variable:

```bash
%AppData%\kdenlive\effects
```
